============================================================
  COMO PUBLICAR O APP DA BORBOLETA ESTÚDIO CRIATIVO
============================================================

São DOIS repositórios no GitHub (conta luanavolponi):

  borboleta         -> PÚBLICO. Só o código (a programação).
                       Nenhum dado, nenhuma senha.
  borboleta-dados   -> PRIVADO. Os dados da empresa
                       (clientes, pedidos, estoque, finanças),
                       no arquivo data/borboleta.db, que o
                       próprio app salva e lê.

Por quê? O Streamlit grátis só aceita 1 app privado por conta
(já é do orçamento). Um app de código público pode ser
publicado à vontade — e continua protegido pelo login.


------------------------------------------------------------
PASSO 1: Deixar o repositório "borboleta" público
------------------------------------------------------------
1. https://github.com/luanavolponi/borboleta/settings
2. Role até o fim ("Danger Zone") > "Change visibility"
   > "Change to public" e confirme.


------------------------------------------------------------
PASSO 2: Criar o repositório de dados (privado)
------------------------------------------------------------
1. https://github.com/new
2. Repository name: borboleta-dados
3. Marque "Private"
4. MARQUE "Add a README file" (precisa ter algo dentro)
5. "Create repository"


------------------------------------------------------------
PASSO 3: Publicar no Streamlit
------------------------------------------------------------
1. https://share.streamlit.io > "Create app"
2. Repository: luanavolponi/borboleta
   Branch: main
   Main file path: app.py
   App URL: ex.: borboleta-estudio
3. "Advanced settings" > Secrets, cole:

   github_token = "MESMO_TOKEN_DO_APP_DO_ORCAMENTO"
   github_repo = "luanavolponi/borboleta-dados"

   [passwords]
   luana = "SENHA_DA_LUANA"
   tayrone = "SENHA_DO_TAYRONE"

   ATENÇÃO: github_repo é o de DADOS (borboleta-dados)!

4. "Deploy"


------------------------------------------------------------
SEGURANÇA
------------------------------------------------------------
- Sem senha nos Secrets, o login fica bloqueado.
- Se o app não conseguir carregar os dados da nuvem, ele
  mostra um aviso vermelho na barra lateral e NÃO salva nada
  (para não apagar os dados de verdade). Recarregue a página;
  se continuar, o github_token provavelmente expirou — troque
  por um novo nos Secrets.


------------------------------------------------------------
PRIMEIRO USO (ordem sugerida)
------------------------------------------------------------
1. ⚙️ Configurações: preço do kWh (conta de luz), valor da
   sua hora de trabalho, margem de lucro, e cadastre a(s)
   impressora(s).
2. 📦 Estoque > Filamentos: cadastre cada rolo (material,
   cor, preço, quanto já têm).
3. 🏷️ Produtos & Preços: use a calculadora com o peso e o
   tempo que o fatiador mostra e salve os produtos.
4. 🧾 Pedidos: comece a lançar as vendas!


------------------------------------------------------------
COMO O APP FUNCIONA SOZINHO
------------------------------------------------------------
- Pedido com "valor recebido" -> entra no Financeiro como
  Venda (e se mudar o valor no pedido, o Financeiro acompanha).
- Pedido marcado como "Entregue" -> as peças saem do estoque
  de prontas; se não tiver pronta, desconta o filamento.
  Se voltar o status ou excluir o pedido, o estoque volta.
- Compra de filamento/insumo no Estoque -> vira despesa no
  Financeiro (dá pra desmarcar).
- "Registrar produção" -> desconta filamento e soma peças
  prontas.
